🔔 연 1회 토큰 갱신

세 가지 모두 11월 초에 만료돼요. PC에서 하는 작업이고 약 20분 걸려요. 순서대로 하세요.

1단계

Claude 토큰

  1. PC 터미널(PowerShell)에서 프로젝트 폴더를 열어요.
  2. claude.cmd setup-token 실행 → Pro 계정으로 승인 → 토큰 복사
  3. 공백이 섞이지 않게 정리한 뒤 확인하고 등록해요. 자세한 명령은 아래 저장소 문서를 보세요.
2단계

SECRETS_PAT (카카오 토큰 자동 갱신용)

  1. GitHub 토큰 만들기
  2. 이름 briefing-secrets, 만료 1년, morning-briefing 저장소만
  3. Repository permissions → Secrets: Read and write → Generate token → 복사 버튼
  4. 터미널: gh secret set SECRETS_PAT --repo dough-man/morning-briefing → 붙여넣기
3단계

쉬기 열쇠 (폰 버튼용)

  1. 같은 주소에서 이름 skip-button, 만료 1년, morning-briefing 저장소만
  2. Repository permissions → Actions: Read and write (2단계와 권한이 달라요) → Generate token → 복사
  3. 폰으로 보내고, 버튼 페이지 아래 "열쇠 다시 입력"에 붙여넣기
4단계

확인

  1. GitHub → Actions → 아침 브리핑 → Run workflow (force + dry_run) → 초록 체크
  2. 폰 버튼 페이지에서 "↩️ 원래대로"를 눌러 카톡 확인 메시지가 오는지 봐요.

자세한 명령·막혔을 때

저장소 dough-man/morning-briefing 의 docs/연간갱신체크리스트.md 와 docs/복구가이드.md 에 전체 명령이 있어요. 새 Claude 에게 "docs/연간갱신체크리스트.md 보고 같이 해줘"라고 해도 돼요.
